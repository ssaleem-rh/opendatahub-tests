# TC-E2E-004: S3 evaluation job unaffected alongside git jobs

**Objective**: Validate that S3-based evaluation jobs continue to
function correctly when git-based jobs are also running, ensuring
no resource contention or API conflicts between storage types.

**Preconditions**:

- EvalHub API deployed with both S3 and git storage source
  support
- S3 bucket `evalhub-test-data` with evaluation test data
- Public test repository `evalhub-test-data-public` exists

**Test Steps**:

1. Submit a git-based evaluation job via
   `POST /api/v1/evaluations/jobs` with `test_data_ref.git`
   specifying the public repository
2. Immediately after, submit an S3-based evaluation job via
   `POST /api/v1/evaluations/jobs` with `test_data_ref`
   specifying the S3 bucket
3. Wait for both jobs to complete
4. Retrieve both jobs via
   `GET /api/v1/evaluations/jobs/{id}`
5. Verify each job completed with the correct storage type and
   metadata

**Expected Results**:

- Both jobs are accepted and return HTTP 200/201
- The git-based job completes with `git_commit_sha` in the
  response
- The S3-based job completes without git-related fields in the
  response
- Neither job interferes with the other's execution or data
  access
- Both jobs reach a completed status
